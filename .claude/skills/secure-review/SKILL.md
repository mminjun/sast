## 지침

방금 작성하거나 수정한 코드를 CLAUDE.md의 보안 규칙 기준으로 검토한다.
새 코드를 작성하지 말고 검토 결과만 보고한다:

1. 비밀번호·시크릿: 평문 저장, 하드코딩된 키, 로그 노출 여부
2. 접근 제어: 클라이언트 입력(ID 등)을 검증 없이 신뢰하는 곳 (IDOR)
3. 파일 처리: 경로 검증 없는 업로드/압축해제/파일접근 (Zip Slip, Path Traversal)
4. 입력 검증: 사용자 입력이 검증 없이 쿼리·명령·경로에 들어가는 곳
5. 권한 체크: 관리자 전용 기능에 역할 확인이 빠진 곳

발견한 문제는 파일:라인 위치와 함께 심각도(높음/중간/낮음)로 보고하고,
수정 방향을 제시한다. 문제없으면 "검토 통과"와 확인한 항목을 보고한다.
